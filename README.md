# 80% Domestic

iPad app for the 80% commissaire at local and national races (no live timing).
Import a start list (Excel, CSV or PDF), tap each rider as they pass the 80% zone, and the app shows gaps
to the leader against the pull time (80% of the leader's first lap), highlights riders at 50% / 75%, marks pulls
and lapped riders, and keeps the pulled order. Works offline; data stays on the device.

Live: https://justinridesabike-creator.github.io/eighty-percent-domestic/
